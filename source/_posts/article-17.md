## Windows/macOS 一键安装流程

安装 OpenClaw 比安装微信还简单，只需要两步：

### 1. 下载安装包

访问 OpenClaw 官方网站，点击对应系统的下载按钮。

- **Windows**：下载 `.exe` 文件，双击运行
- **macOS**：下载 `.dmg` 文件，拖动到 Applications 文件夹

### 2. 一键启动

安装完成后，点击 OpenClaw 图标，程序会自动完成：
- Node.js 环境检测与安装
- 依赖包自动下载
- 配置文件生成

{% note warning %}
⚠️ **注意事项**：
- Windows 用户需要以管理员身份运行
- macOS 用户可能需要允许“来自任何来源”的应用
- 首次启动可能需要 2-3 分钟，请耐心等待
{% endnote %}

## 首次启动：配置 WhatsApp 集成

OpenClaw 的主要交互方式是 WhatsApp，这意味着你可以在手机上随时指挥你的 AI 助手。

### 1. 扫描二维码

首次启动后，会看到一个 WhatsApp 二维码。

1. 打开 WhatsApp（手机端）
2. 点击右上角三个点 → Linked Devices
3. 点击 Link a Device
4. 扫描电脑上的二维码

### 2. 验证连接

扫描成功后，你会收到 OpenClaw 的欢迎消息：

> 👋 你好！我是你的 AI 个人助手小白。
> 
> 我可以帮你：
> - 整理文件
> - 查天气
> - 管理日程
> - 自动回复消息
> - 等等...
> 
> 发送 `help` 查看完整功能列表。

## 第一个任务：让 AI 帮你整理桌面文件

现在，让我们来做第一个任务——让 AI 帮你整理桌面文件。

### 1. 发送指令

在 WhatsApp 中发送：

```
帮我整理桌面文件，按类型分类
```

### 2. AI 的工作流程

1. **理解指令**：AI 分析你的需求，确定要执行的动作
2. **获取权限**：如果第一次运行，会请求文件系统访问权限
3. **执行任务**：
   - 扫描桌面文件
   - 按文件类型（图片、文档、视频、音乐）分类
   - 创建对应文件夹并移动文件
4. **反馈结果**：任务完成后，AI 会发送一份详细的报告

### 3. 任务结果示例

```
✅ 桌面整理完成！

整理了 23 个文件：
- 图片：5 个 → 移动到 Desktop/Pictures
- 文档：8 个 → 移动到 Desktop/Documents
- 视频：3 个 → 移动到 Desktop/Videos
- 音乐：2 个 → 移动到 Desktop/Music
- 其他：5 个 → 移动到 Desktop/Other

耗时：32 秒
```
