## scikit-learn 介绍

scikit-learn 是一个开源的机器学习库，基于 Python 语言。它提供了简单易用的 API，帮助我们快速构建机器学习模型。scikit-learn 支持多种机器学习算法，包括分类、回归、聚类、降维等。

### 特点
- 简单易用：API 设计简洁，易于学习和使用
- 丰富的算法：支持多种机器学习算法
- 强大的工具：提供数据预处理、模型评估、特征工程等工具
- 社区活跃：有大量的用户和贡献者，文档丰富

### 安装
安装 scikit-learn 非常简单，只需要使用 pip 命令即可：
```bash
pip install scikit-learn
```

### 常用 API
scikit-learn 的 API 设计非常一致，对于大多数算法，都可以使用以下步骤：
1. 导入算法类
2. 初始化模型
3. 训练模型
4. 预测

## 分类算法

分类是机器学习中最常见的任务之一。scikit-learn 提供了多种分类算法，包括逻辑回归、决策树、随机森林、支持向量机等。

### 逻辑回归
逻辑回归是一种线性分类算法，适用于二分类问题。它通过计算概率来判断样本属于哪个类别。

### 决策树
决策树是一种非线性分类算法，通过构建树结构来进行分类。决策树的优点是易于理解和解释，但容易过拟合。

### 随机森林
随机森林是一种集成学习算法，通过集成多个决策树来提高模型的准确性和稳定性。随机森林的优点是不易过拟合，适用于大规模数据集。

### 支持向量机
支持向量机是一种强大的分类算法，适用于线性和非线性分类问题。它通过寻找最优超平面来分离不同类别的样本。

## 回归算法

回归是机器学习中另一个常见的任务，用于预测连续值。scikit-learn 提供了多种回归算法，包括线性回归、多项式回归、岭回归、Lasso 回归等。

### 线性回归
线性回归是一种简单的回归算法，适用于线性关系的数据集。它通过拟合一条直线来预测连续值。

### 多项式回归
多项式回归是一种非线性回归算法，适用于非线性关系的数据集。它通过拟合一条曲线来预测连续值。

### 岭回归
岭回归是一种正则化的线性回归算法，通过添加 L2 正则化项来防止过拟合。

### Lasso 回归
Lasso 回归是另一种正则化的线性回归算法，通过添加 L1 正则化项来防止过拟合。Lasso 回归还可以用于特征选择。

## 模型评估

模型评估是机器学习中非常重要的一步，它帮助我们判断模型的性能。scikit-learn 提供了多种模型评估工具，包括准确率、精确率、召回率、F1 值、ROC 曲线等。

## 特征工程

特征工程是机器学习中非常重要的一步，它帮助我们提取和选择最有效的特征。scikit-learn 提供了多种特征工程工具，包括数据清洗、特征选择、特征缩放等。
